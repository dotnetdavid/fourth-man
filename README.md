# Fourth Man

Fourth Man is a Hermes skill for structured dissent on consequential claims. It asks a separate analyst to build the strongest credible countercase before a human makes a decision.

It is not a voting system, approval gate, source of independent evidence, or replacement for accountable human judgment. It may conclude that there is no material objection.

## What it does

- freezes three initial analyses before debate;
- tests shared assumptions with an evidence-grounded countercase;
- preserves uncertainty and unresolved dissent;
- identifies checks that could prove a conclusion wrong;
- produces a human decision brief without making the decision.

## Safety boundary

The skill is cross-domain but does not provide individual medical diagnosis, treatment, medication, triage, or emergency advice. For medical topics, it supports public evidence appraisal only.

## Install in Hermes

Copy the complete repository folder into your active Hermes profile's `skills/` directory so that `fourth-man/SKILL.md` remains together. Start a new Hermes session after installation.

## Repository boundary

This repository contains the reusable skill source. Private experiments, evaluator-only material, and project-specific decision records belong in their own private workspaces and are not published here.
